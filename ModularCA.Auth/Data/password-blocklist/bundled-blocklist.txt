# ModularCA bundled password blocklist: STARTER LIST.
#
# A starter list written for ModularCA from the kinds of password every "worst passwords" list
# contains: number and alphabet runs, keyboard walks, "password" and its variants, account
# names and defaults, seasons and years, the product's own name and subject, stock phrases and
# the names and words people reach for first. It is NOT a compromised-password corpus and is
# far smaller than one. It stops the obvious choices and nothing more.
#
# Used when the password policy has "Check the bundled blocklist" on. A new password is
# refused when, ignoring case, it equals an entry, or is one entry (or any one or two
# characters) repeated end to end. An administrator's own list in
# config/password-dictionaries is checked in addition to this one.
#
# Format: UTF-8, one password per line, compared without regard to case. Blank lines and
# lines that start with "#" are ignored. This file is replaced by every upgrade: put
# additions in a file of your own under config/password-dictionaries, not here.
